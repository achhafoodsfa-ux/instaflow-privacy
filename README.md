# InstaFlow

InstaFlow is a personal automation tool operated by its owner. It connects the owner's Google Drive to the owner's Instagram account: videos placed in a dedicated Drive folder are edited and published as Reels on the owner's own Instagram account.

## Privacy Policy

Last updated: October 20, 2026

**Data accessed.** With the owner's authorization, InstaFlow accesses files in the owner's Google Drive (the "Instagram Automation" folder) and publishes content to the owner's Instagram account through Meta's official API.

**How data is used.** Files are processed only to perform the automation the owner configured: downloading videos, editing them, uploading the processed result, and moving files between the tool's own Drive folders. Processing runs on GitHub Actions using credentials stored as encrypted repository secrets.

**Sharing.** No data is sold, rented, or shared with third parties. No advertising, analytics, or tracking is used.

**Retention.** Videos and processed files remain in the owner's own Google Drive. The owner can revoke access at any time from their Google Account's third-party access page or by deleting the repository secrets.
